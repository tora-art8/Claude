Manga Çeviri TR — Ayarlar

1. Çeviri motoru

Ücretsiz motoru hazırla

İlk kullanımda Chrome Türkçe çeviri paketini bir kez indirir. Aşağıdaki düğme paketi indirir ve örnek bir cümle çevirerek motorun çalıştığını gösterir.

Claude API anahtarı

Anahtar yalnızca bu tarayıcıda (chrome.storage.local) saklanır, hiçbir siteye gönderilmez; sadece api.anthropic.com'a iletilir.

API anahtarı nasıl alınır?
  1. platform.claude.com adresinde hesap aç.
  2. Billing bölümünden küçük bir bakiye yükle (ör. 5 $).
  3. API Keys bölümünden yeni anahtar oluştur, kopyala ve buraya yapıştır.

2. Görünüm

Yazı bu boyutun altına inmeden sığmıyorsa Claude motorunda çeviri kısalttırılır, ücretsiz motorda yazı biraz daha küçültülür.
